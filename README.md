# 4399 赛尔号精灵图鉴增强插件

4399 Seer Pet Dex Enhancer

版本：1.0.2 · 油猴用户脚本 · MIT

## 安装

1. 在 Chrome 中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 在 Chrome 的扩展管理页面打开 Tampermonkey 详情，启用“允许用户脚本”；旧版 Chrome 可按 Tampermonkey 提示启用开发者模式。
3. 打开 Tampermonkey 的“添加新脚本”编辑器，把默认内容全部替换为 `seer-4399-enhancer.user.js` 的完整内容，保存并确认脚本已启用。
4. 刷新已经打开的 4399 图鉴和计算器页面。

升级后应先刷新图鉴，再从图鉴重新点击“精灵计算器”。只刷新之前直接打开的计算器标签页，未必带有待选择的精灵信息。

也可以使用 Tampermonkey 管理面板中的文件导入功能导入 `.user.js` 文件。当前是本地交付版本，尚未发布到脚本平台，未配置在线更新地址；新版可用同样方式替换。

## 本地调试

复制 `seer-4399-enhancer.dev.user.js.example` 为 `seer-4399-enhancer.dev.local.user.js`，将 `@require` 的 `file:///ABSOLUTE/PATH/` 替换为仓库绝对路径。使用本地入口作为油猴入口，并停用油猴中另外安装的完整脚本。该入口通过 `@require` 加载仓库目录的主脚本；如果移动文件，需同步修改入口中的绝对路径。

在 Chrome 扩展详情中为 Tampermonkey 开启“允许访问文件网址”和“允许运行用户脚本”。保存本地的主脚本后刷新图鉴，再点击计算器。已在独立的 Chrome for Testing 152 / Tampermonkey 5.5.0 中验证本地文件更新后刷新会加载新版本。

在开发者工具 Console 中应能看到 `[4399增强] v1.0.2 已启动`。可运行以下命令确认主脚本是否加载：

```js
document.getElementById('seer-plus-loaded')?.dataset.version ?? '未注入'
```

在计算器页运行 `window.petid`，卡其沙应为 `p106`。如果显示“未注入”，先检查入口是否已保存并启用、文件访问权限、`@require` 路径及 Console 的加载错误；此时还没进入精灵匹配逻辑。

## 1.0.2 链接简化

图鉴打开计算器时只通过 `#pet=p106` 传递网站内部精灵 ID，例如：

```text
https://news.4399.com/seer/jsq/#pet=p106
```

计算器直接读取原站 `pets` 中对应的记录。链接不再包含 JSON、名称、图鉴路径或浏览形态。无效或不存在的 ID 会显示提示，不改变当前选择；不带参数时保留原站默认行为。旧版 `#seerPlus=...` 链接会提示重新从图鉴打开。

## 1.0.1 修复

4399 评论兼容脚本将任意 `postMessage` 字符串当成回复指令，可能被浏览器扩展消息误触发。新增回复入口参数校验，拒绝缺少有效评论编号的调用，并关闭已出现的无效回复框。正常评论回复仍可使用；没有全局拦截 `message` 事件。

新增启动版本及计算器就绪日志，用于区分未注入、加载未就绪和精灵匹配问题。

## 使用

- 打开[卡其沙图鉴](https://news.4399.com/seer/tujian/63938.htm)，点击种族值旁的“精灵计算器”。新标签页会自动选中卡其沙，并更新列表选中态、图片和六项种族值。
- 能力值计算区上方提供固执、保守、胆小、开朗四个快捷按钮，直接显示增强和削弱属性。点击后会同步原站下拉框和修正系数。
- 展开“全部 25 种性格”可按增强属性查看并选择所有性格。五种平衡性格均标注“无增减”。
- 选择性格后，继续使用原站的“计算”按钮。性格变化会清除旧结果，保留等级、个体值和学习力等输入。
- 个体值计算区同样提供性格选择；计算体力时隐藏性格面板，因为体力不受性格影响。两个计算区的选择相互独立。
- 手动修改原站的单项性格修正系数后，面板显示“自定义修正”；再次点击性格即可恢复对应的标准修正。

## 支持范围

适用于 `news.4399.com` 的桌面赛尔号图鉴及 `/seer/jsq/` 计算器，支持 HTTP 和 HTTPS、`/seer/` 和 `/gonglue/seer/` 两种图鉴路径。手机站暂不支持。

第一版按图鉴主精灵联动。原计算器把同一图鉴的多个进化形态归在一条记录中；例如水草蛙/卡其沙这一条只提供卡其沙的种族值。如果在图鉴切到水草蛙后打开计算器，仍选择卡其沙；链接不再记录之前浏览的形态，计算器统一提示按图鉴主精灵数据计算。

精灵身份随每条链接携带，无需保存“最近浏览精灵”，可分别打开多个计算器标签页。编号无效或不存在时会显示提示，由用户手动搜索选择。

脚本使用原站提供的精灵、性格数据及计算逻辑，不内置额外精灵数据库。`unsafeWindow` 权限用于读取这些页面数据和调用原站选择函数。脚本自身不发送网络请求、不收集账号信息、不添加统计、不保存浏览记录。
