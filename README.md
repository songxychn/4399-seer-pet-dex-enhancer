# 4399 赛尔号精灵图鉴增强插件

4399 Seer Pet Dex Enhancer · 油猴用户脚本 · MIT

增强 4399 赛尔号桌面精灵图鉴、精灵计算器和属性相克表，让图鉴信息与工具直接联动。

[Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/596509) · [版本更新](https://github.com/songxychn/4399-seer-pet-dex-enhancer/releases) · [问题反馈](https://github.com/songxychn/4399-seer-pet-dex-enhancer/issues)

## 功能

- **属性相克表联动**：从图鉴点击“精灵属性表”或属性文字，自动选中对应属性，同步高亮、标题、攻击和被攻击效果。兼容属性别名与双属性顺序差异。
- **精灵计算器联动**：从图鉴打开计算器时，自动选中对应主精灵，并更新图片、列表选中状态和种族值。
- **性格快捷选择**：突出固执、保守、胆小、开朗，展示全部 25 种性格的增强与削弱属性，同步原站计算选项。
- **评论回复框保护**：过滤无效评论回复参数，减少图鉴和计算器中误弹“我要回复”的情况。

## 安装与更新

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。在 Chrome 的扩展详情中启用“允许用户脚本”；旧版 Chrome 可按 Tampermonkey 提示启用开发者模式。
2. 打开 [Greasy Fork 安装页面](https://greasyfork.org/zh-CN/scripts/596509)，点击安装，并在脚本管理器中确认。
3. 刷新已经打开的图鉴、计算器和属性相克表页面。

也可以在脚本管理器中新建脚本，粘贴 [主脚本](seer-4399-enhancer.user.js) 的完整内容并保存，或使用文件导入功能导入 `.user.js`。

更新后应先刷新图鉴，再从图鉴重新打开计算器或属性相克表，以携带当前精灵或属性信息。各版本更新内容见 [GitHub Releases](https://github.com/songxychn/4399-seer-pet-dex-enhancer/releases)。

## 使用

### 属性相克表

打开[菲拉斯特图鉴](https://news.4399.com/seer/tujian/76202.htm)，点击“精灵属性表”或“战斗地面系”文字，新标签页会自动选中“战斗地面”。属性文字保持无下划线；中键和右键“在新标签页打开”同样有效。

属性按点击入口所属的进化形态读取。支持“地/地面”“冰雪/冰”“飞龙/飞行龙”等别名，以及“火电/电火”“地面机械/机械地面”等双属性顺序差异。

直接打开不带参数的相克表时保留原站默认选择。无法找到唯一对应属性时会显示提示，可在左侧手动选择；等待加载期间已手动选择时，不再覆盖。目标页也需要启用本脚本。

### 精灵计算器

打开[卡其沙图鉴](https://news.4399.com/seer/tujian/63938.htm)，点击种族值旁的“精灵计算器”，新标签页会自动选中卡其沙。

- 能力值计算区上方提供固执、保守、胆小、开朗四个快捷按钮，点击后同步性格下拉框和修正系数。
- 展开“全部 25 种性格”可按增强属性查看和选择，五种平衡性格均标注“无增减”。
- 选择性格后，继续使用原站“计算”按钮。性格变化会清除旧结果，保留等级、个体值和学习力等输入。
- 个体值计算区同样提供性格选择；计算体力时隐藏性格面板。两个计算区的选择相互独立。
- 手动修改单项性格修正系数后，面板显示“自定义修正”；再次点击性格可恢复标准修正。

效果示例：[性格快捷选择](docs/images/性格快捷选择.png)、[全部性格](docs/images/全部性格.png)、[油猴自动选择验证](docs/images/油猴自动选择验证.png)。

## 支持范围与限制

支持 `news.4399.com` 桌面站的精灵图鉴、`/seer/jsq/` 计算器和 `/seer/ssxxk/` 属性相克表，兼容 HTTP、HTTPS，以及 `/seer/`、`/gonglue/seer/` 两种图鉴路径。手机站暂不支持。

计算器按图鉴主精灵数据联动。原站会把多个进化形态合并为一条记录；例如水草蛙/卡其沙只提供卡其沙的种族值，因此切到水草蛙后打开计算器仍选择卡其沙。

精灵和属性信息随每条链接传递，多个标签页互不影响，无需保存“最近浏览精灵”。精灵编号无效或不存在时会显示提示，由用户手动搜索选择。

脚本使用原站精灵、性格、属性数据和计算逻辑，不内置额外精灵数据库。`unsafeWindow` 权限用于读取页面数据和调用原站函数。增强脚本自身不发送网络请求、不收集账号信息、不添加统计、不保存浏览记录。

## 本地调试与验证

复制 [本地入口示例](seer-4399-enhancer.dev.user.js.example) 为 `seer-4399-enhancer.dev.local.user.js`，将 `@require` 的 `file:///ABSOLUTE/PATH/` 替换为仓库绝对路径。使用该入口加载主脚本，并停用脚本管理器中另外安装的完整脚本；移动仓库后需同步修改路径。

在 Chrome 扩展详情中为 Tampermonkey 开启“允许访问文件网址”和“允许用户脚本”。修改主脚本后刷新页面，Console 中应出现 `[4399增强]` 启动日志。可检查当前加载版本：

```js
document.getElementById('seer-plus-loaded')?.dataset.version ?? '未注入'
```

若显示“未注入”，检查入口是否保存并启用、文件访问权限、`@require` 路径及 Console 错误。从卡其沙图鉴打开计算器后，可运行 `window.petid`，预期为 `p106`。

已安装 agent-browser CLI 及其无头浏览器时，可运行全量属性回归：

```bash
python3 scripts/verify-attribute-links.py --output /tmp/seer-type-results.json
```

测试使用独立会话和页面加载后注入。各次验证的方法、覆盖范围和限制见 [验证记录](docs/验证记录.md)；页面注入通过不代表真实油猴自动加载已验证。
