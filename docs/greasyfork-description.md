增强 4399 赛尔号电脑端精灵图鉴、精灵计算器和属性相克表，让图鉴信息与工具直接联动。安装后继续使用原来的 4399 页面即可，不需要写代码。

## 从图鉴直接进入精灵计算器

打开[卡其沙图鉴](https://news.4399.com/seer/tujian/63938.htm)，点击“卡其沙种族值”标题右侧红框标出的计算器图标：

![红框与箭头标出种族值标题右侧的精灵计算器入口](https://raw.githubusercontent.com/songxychn/4399-seer-pet-dex-enhancer/master/docs/images/dex-calculator-entry-annotated.png)

新标签页会自动选中卡其沙，并显示图片和种族值，省去在计算器里再搜一次名字的步骤。多个图鉴分别打开工具时，各自携带对应信息。

## 选性格、填学习力，再开始计算

例如试算卡其沙的保守攻速，可以按图中编号操作：

1. 点击“保守”，选择性格。
2. 点击“攻速”，给特攻和速度各填入 255 学习力。
3. 确认等级和个体值，再点击能力值计算区的“开始计算”。

![按编号依次选择性格、加点方案，再点击能力值计算区的开始计算](https://raw.githubusercontent.com/songxychn/4399-seer-pet-dex-enhancer/master/docs/images/calculator-shortcuts-annotated.png)

快捷按钮只填写网页计算器，不修改游戏里精灵的学习力。原站页面将学习力写作“努力值”。

### 常用性格快捷选择

根据当前精灵的攻击、特攻种族值显示常用按钮：

| 种族值情况 | 快捷显示的性格 |
| --- | --- |
| 攻击高于特攻 | 固执、开朗 |
| 特攻高于攻击 | 保守、胆小 |
| 攻击与特攻相同 | 固执、保守、胆小、开朗 |

每种性格都标明增强、削弱哪项能力。展开“全部 25 种性格”可选择其他性格，五种平衡性格标注“无增减”。“常用”只是按种族值筛选出的快捷入口，具体培养仍需结合技能和用途判断。

能力值、个体值两个计算区的性格选择相互独立；切换精灵不会自动更改已选性格或自定义修正。计算体力个体值时隐藏性格面板，因为体力不受性格影响。

### 学习力快捷调整

- **清零**：只把当前项设为 0。
- **最大**：根据其他五项的剩余额度尽量填满，单项最多 255、总额最多 510，不修改其他项。
- **攻体、攻速**：给种族值较高的攻击项分配 255，再给体力或速度 255，其余四项清零。攻击与特攻相等时，提供物攻体、特攻体、物攻速、特攻速四种选择。

**点击加点方案会覆盖六项输入**，等级、个体值和性格保持不变。面板实时显示已分配、剩余额度；手动输入超额或非法数值时会提示，不自动改写其他输入。修改性格或学习力后旧结果会清空，需要重新点击“开始计算”。

## 从图鉴直接查看属性相克

打开[菲拉斯特图鉴](https://news.4399.com/seer/tujian/76202.htm)，图中红框标出了两个入口，任选一个即可：

- **入口一**：点击“精灵属性”标题右侧的属性表图标。
- **入口二**：点击下方“战斗地面系”文字。

![红框与箭头标出属性表图标和属性文字两个入口](https://raw.githubusercontent.com/songxychn/4399-seer-pet-dex-enhancer/master/docs/images/dex-type-entry-annotated.png)

新标签页自动选中“战斗地面”，同步高亮、标题、攻击和被攻击效果。按点击入口所属的进化形态读取属性；中键和右键“在新标签页打开”同样有效。

兼容属性别名和双属性顺序差异，例如“地/地面”“飞行龙/飞龙”“火电/电火”。直接打开相克表时保留原站默认选择，仍可手动切换。

## 安装与更新

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。Chrome 用户在扩展详情中启用“允许用户脚本”；旧版 Chrome 没有此开关时可启用开发者模式，具体入口见[官方带图说明](https://www.tampermonkey.net/faq.php?locale=zh&q=Q209)。
2. 点击本页“安装此脚本”，在脚本管理器中确认安装。
3. 刷新已经打开的图鉴，再从图鉴重新进入计算器或属性相克表。目标工具页面也需要启用本脚本。

安装后可以用上面的卡其沙图鉴试一次：计算器自动选中卡其沙，并出现性格和学习力面板，就说明增强功能已生效。更新脚本后同样需要刷新图鉴，再重新打开工具。

没有变化时，请确认脚本已启用，并检查用户脚本权限。不想使用时，在油猴管理面板里停用本脚本，刷新页面即可。

## 支持范围与说明

支持 `news.4399.com` 电脑端的精灵图鉴、精灵计算器和属性相克表，兼容 HTTP、HTTPS，以及 `/seer/`、`/gonglue/seer/` 两种图鉴路径。手机站暂不支持。

计算器按图鉴主精灵数据联动。原站将多个进化形态合并为一条记录时，使用其提供的主精灵种族值；例如从水草蛙/卡其沙图鉴进入时按卡其沙计算。匹配不到精灵或属性时会提示，可手动选择。

另外，脚本过滤无效评论回复参数，减少图鉴和计算器里误弹“我要回复”的情况。

使用原站精灵、性格、属性数据和计算逻辑，不内置额外精灵数据库。增强脚本自身不发送网络请求、不收集账号信息、不添加统计、不保存浏览记录。`unsafeWindow` 权限用于读取页面数据和调用原站函数。
